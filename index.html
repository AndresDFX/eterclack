EterClack

Marketplace de servicios fotográficos. Reserva directa sobre calendario, contrato con evidencia y pagos con dispersión al fotógrafo.

Sobre este sitio

Aquí está la documentación del proyecto y las capturas de la interfaz. La aplicación no corre en esta dirección: GitHub Pages sirve archivos estáticos, y la plataforma necesita API, base de datos, almacenamiento y sesiones. Su destino es un VPS — el detalle está en el plan de despliegue.

Cómo levantarla

Requisito único: Docker.

git clone <este-repositorio>
cd eterclack
cp .env.example .env
npm run up
npm run db:migrate
npm run db:seed

La web queda en localhost:5173 y los correos se capturan en localhost:8025.
